# pi-gui fork 
(work in progress)

[`pi-gui/`](pi-gui/) holds a fork of [pi-gui](https://github.com/minghinmatthewlam/pi-gui), a desktop app for the pi agent. It adds a one-click Microsoft 365 Copilot connection, OpenUI rich answer cards and coworker-friendly defaults for Windows. See [`pi-gui/FORK.md`](pi-gui/FORK.md).
